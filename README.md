# YouX VPN

Клиент YouX VPN для **Windows, Android и Linux**. Одно приложение, один аккаунт,
одинаковый интерфейс на всех платформах.

Здесь публикуются готовые дистрибутивы. Исходный код закрыт.

## Скачать — версия 1.3.0

| Платформа | Файл | Размер | Требования |
|---|---|---|---|
| Windows | `YouX-VPN-1.3.0.msi` | ~125 МБ | Windows 10/11, 64-бит |
| Android | `YouX-VPN-1.3.0.apk` | 20 МБ | Android 8.0 и новее |
| Linux | `YouX-VPN-1.3.0-amd64.deb` | 116 МБ | Ubuntu 22.04+ / Debian 12+, 64-бит |

Все файлы — на вкладке [Releases](../../releases/latest). Java и другие зависимости
ставить не нужно: всё необходимое уже внутри пакета.

**Проверка целостности.** Рядом с файлами лежит `SHA256SUMS.txt`. Сверить:

```bash
sha256sum -c SHA256SUMS.txt          # Linux
```
```powershell
Get-FileHash "YouX-VPN-1.3.0.msi" -Algorithm SHA256   # Windows
```

Сверять стоит не для формальности: APK ставится мимо магазина, и совпадение суммы —
единственный способ убедиться, что файл не подменён по дороге.

## Установка

### Windows
1. Скачайте `.msi` и запустите его. Установка идёт **без прав администратора**, в профиль
   пользователя; появятся ярлык на рабочем столе и пункт в меню «Пуск».
2. При **первом** подключении Windows один раз спросит подтверждение администратора —
   так ставится системная служба туннеля `YouXVPNAgent`. Дальше подключения идут без
   лишних окон.
3. Удаление — обычное, через «Параметры → Приложения». Служба и все данные приложения
   удаляются автоматически в течение пары минут после удаления программы (остаток
   служебных файлов исчезает после перезагрузки).

### Android
1. Скачайте `.apk`. Android предупредит об установке из неизвестного источника —
   разрешите установку для браузера/файлового менеджера, из которого открываете файл.
2. При первом подключении система запросит разрешение на создание VPN-соединения.

Приложения нет в Google Play — устанавливайте только APK из этого репозитория и
сверяйте контрольную сумму.

### Linux
```bash
sudo apt install ./YouX-VPN-1.3.0-amd64.deb
```
Запуск — из меню приложений или командой `/opt/youx-vpn/bin/"YouX VPN"`.
При первом подключении менеджер политик (polkit) один раз спросит пароль — так
регистрируется системный агент туннеля `youx-vpn-agent`. Дальше — без запросов.

## Что внутри

- **AmneziaWG 2.0** — основной протокол. Это не обычный WireGuard: трафик маскируется
  набором параметров обфускации, чтобы его не отсекала фильтрация по сигнатуре протокола.
- **VLESS через CDN** — запасной режим для сетей с «белыми списками», где заблокировано
  почти всё, кроме нескольких разрешённых сервисов. Соединение идёт через сеть доставки
  контента, а приложение само распределяет трафик между несколькими точками входа и
  переключается на резервные, если основная перестала отвечать. Для VLESS доступен
  выбор локации и включён ежемесячный лимит трафика с возможностью докупить объём.
- **Исключения VPN** (раздельное туннелирование) — выбранные программы ходят мимо VPN,
  либо наоборот: через VPN идут только они. Работает на Android и Windows. На Windows
  приложение опознаётся по пути к файлу программы, а не по имени процесса.
- **Выбор локации**, счётчики скорости и трафика, автозапуск и работа из системного
  трея (Windows/Linux).

## Поддержка

Вопросы и проблемы — через раздел «Поддержка» в самом приложении: оттуда обращение
попадает напрямую в нашу очередь вместе с диагностикой. Если приложение не запускается,
пишите на [issues](../../issues) — приложите версию ОС и файл журнала:

- Windows: `%APPDATA%\YouXVPN\youx-desktop.log`
- Linux: `~/.config/youx-vpn/youx-desktop.log`
- Android: «Настройки → Отправить журнал»
